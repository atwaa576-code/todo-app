# React To-Do List

A simple and functional To-Do List application built with React.js.

## Features

- Add new tasks
- Delete tasks
- Edit tasks
- Mark tasks as completed
- Clear all tasks
- Display completed and remaining tasks
- Responsive design

## Technologies

- React.js
- JavaScript
- CSS
- HTML

## What I Learned

- Managing state with useState
- Handling user input and events
- Working with arrays and objects
- Using map(), filter(), and find()
- Conditional rendering
- Creating a responsive UI
- Deploying a React project
